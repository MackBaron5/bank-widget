# Приложение для анализа финансовых транзакций

## Описание
Бэкенд-система для генерации аналитических отчетов, умного поиска по транзакциям и формирования веб-страниц "Главная" и "События".

## Как запустить приложение
```bash
python -m src.main
```

## Как запустить тесты
```bash
poetry run pytest
```
